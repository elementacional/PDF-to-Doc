# PDF to DOCX Engine ABNT

Versão preparada para hospedagem estática no GitHub Pages.

## Estrutura

```text
/
├── index.html
└── README.md
```

## Publicação

1. Crie um repositório no GitHub.
2. Envie `index.html` e `README.md` para a raiz.
3. Vá em **Settings → Pages**.
4. Selecione **Deploy from a branch**.
5. Branch: `main`.
6. Pasta: `/ (root)`.
7. Salve e aguarde a publicação.

## Observação

O processamento é executado no navegador. O GitHub Pages hospeda a interface; não é necessário um servidor PHP/Python/Node para o fluxo principal.

A aplicação utiliza recursos externos por HTTPS/CDN e alguns recursos opcionais dependem de conexão com a internet.
